# Jatin Seelam Portfolio

A responsive single-page portfolio for Data Engineering, AI/ML and Full Stack Web Development.

## Files

- `index.html` — portfolio content
- `styles.css` — responsive UI and animations
- `script.js` — mobile menu and footer year
- `passport.jpg` — uploaded profile photo

## Before publishing

Open `index.html` and replace:

- `YOUR_EMAIL@example.com`
- `https://www.linkedin.com/in/YOUR_LINKEDIN/`
- `https://github.com/YOUR_GITHUB`

You can also edit project descriptions and add direct GitHub/demo links to the project cards.

## Run locally

Open `index.html` directly in a browser, or use VS Code Live Server.

## Deploy

This is a static site, so it can be deployed to GitHub Pages, Netlify, Vercel, or any static hosting provider.
